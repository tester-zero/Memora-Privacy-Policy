01

Application Scope & Identity

This Privacy Policy governs the Memora — Visual Note & Photo Organizer mobile application (hereinafter referred to as "Memora", "the Application", "we", "our", or "us"), package name com.onelinestudio.memora, published by OneLineStudio on the Google Play Store.

Memora is created to provide a quiet, distraction-free visual notebook for everyday reference photos (e.g., receipts, appliance serial numbers, Wi-Fi codes, notes). Because privacy is our core principle, the Application is engineered from the ground up as a standalone, offline utility that does not communicate with external servers.

02

Information We Collect and Handle

Memora complies with the principle of strict data minimization. We only process data that you explicitly choose to create or import into the Application.

A. Data Handled Locally on Your Device

  • Visual Notes (Photos): Images captured via your device camera or selected from your device photo picker upon your explicit action. These images are stored exclusively inside the app's sandboxed local internal directory on your physical device.
  • Note Metadata: Titles, custom descriptive tags (e.g., "Receipts", "Work", "Home"), and timestamp metadata created by you. This metadata is stored locally in an on-device SQLite / Room database.
  • User Preferences: Your selected theme preference (Light Mode or Dark Mode) and custom tag list, saved on your device using Android SharedPreferences.

B. Data We Do NOT Collect

What We Never Collect:
  • No Personal Identifiers: We do not collect names, email addresses, physical addresses, or phone numbers.
  • No Accounts or Logins: Memora requires no user accounts, passwords, or social authentication.
  • No Device or Advertising Identifiers: We do not track GAID (Google Advertising ID), Android ID, IMEI, or MAC addresses.
  • No Location Data: Memora never requests, accesses, or processes GPS or network location data.
  • No Financial or Biometric Data: No payment details or biometric information are accessed or processed.
  • No Analytics or Telemetry: No analytics SDKs, session trackers, or telemetry tools are installed.
03

How User Data is Stored and Processed

All operations and data processing in Memora occur 100% locally on your device:

  • Internal Sandboxed Storage: Photos you add to Memora are saved into the application's isolated private files directory (context.filesDir/photos). Other apps on your device cannot access this folder.
  • Local Database: Photo records, titles, and tag associations are stored locally in an on-device Room database. No cloud database or remote synchronization is utilized.
  • Zero Network Transmission: The Application manifest deliberately omits the android.permission.INTERNET permission. Memora is programmatically barred by the Android operating system from establishing outbound network connections or sending data over the internet.
  • No Cloud Backups: System auto-backup is disabled (android:allowBackup="false") to ensure your reference pictures do not silently upload to external third-party cloud servers without your explicit knowledge.

06

Data Retention and User Deletion Rights

You possess complete, autonomous ownership over all your data in Memora:

  • Single Photo Deletion: When viewing any photo card, tapping the Delete button permanently deletes the image file from internal storage and purges its record from the database.
  • Bulk Photo Deletion: Long-pressing photo cards enters multi-selection mode, allowing you to select and permanently remove multiple entries in a single action.
  • Tag Editing and Removal: You can edit, rename, or delete tags at any time via the Menu screen. Deleting a tag immediately detaches it from all associated photos.
  • Total App Data Deletion: You can clear all data at any time via Android Settings → Apps → Memora → Storage → Clear Data, or by simply uninstalling the Application. Uninstalling Memora permanently eradicates all stored images, tags, and database records from your device.
  • No Residual Cloud Copies: Because Memora does not possess internet access or cloud synchronization, deleted items cannot be recovered from any remote server.

08

Technical Security Safeguards

We implement industry-standard software engineering practices to safeguard your visual notes on your device:

  • Path Traversal Defense: All file access strictly validates file canonical paths to prevent directory traversal exploits.
  • Input Sanitization: Titles and custom tags are sanitized to remove control characters and enforce strict size boundaries.
  • Magic Byte Validation: All imported image files are verified by inspecting header magic bytes (JPEG, PNG, WebP) to prevent malicious executable injection.
  • Memory Bounds Protection: Bitmap dimensions are checked prior to decoding to prevent memory exhaustion and denial-of-service attempts.
  • Isolated Sandboxing: Files are stored within Android's private app sandbox, preventing unauthorized access by other installed applications.
